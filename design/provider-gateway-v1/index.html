09 · 状态与保障

flowchart TD
 A[请求] --> B{前置检查}
 B -->|安全拒绝| BLOCK[blocked · 不转发]
 B -->|凭据/协议失败| FAIL[failed · 可定位错误]
 B -->|通过| RUN[running]
 RUN --> DONE[协议 completed]
 RUN --> INC[协议 incomplete / failed]
 RUN --> DISC[客户端断开 · 关闭上游流]
 RUN --> RESTART[进程重启 → interrupted]
 DONE --> EOF{HTTP EOF?}
 EOF -->|是| FULL[正文已收全]
 EOF -->|否| PART[协议完成 · 正文部分保留]
 INC & DISC --> PART
 CAP[落盘异常恢复 · 待补验收] -.-> RUN
 TIME[连接/读取超时 + 总时长界限] -.-> RUN
 OBS[metadata observer 1 MiB · 非正文截断上限] -.-> RUN
