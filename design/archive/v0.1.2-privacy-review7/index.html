02 · 网关架构与代码落点

flowchart TB
 C[客户端请求] --> B[privacy/buffer.py · 完整有界缓冲]
 B --> S[privacy/policy.py · 不可变策略快照]
 S --> P[privacy/parsers · 已支持协议的请求结构]
 P --> D[privacy/detector.py · 本机规则 / 字段与上下文]
 D --> R[privacy/redactor.py · 原值到占位符的请求内映射]
 R --> V[privacy/validator.py · 结构与残留校验]
 V --> A[privacy/records.py · 最小风险元数据持久化]
 A --> G[唯一出站授权点 · SanitizedRequest]
 G --> T[既有 provider/transport.py]
 T --> AUTH[既有 Provider鉴权 / 可信凭据注入]
 AUTH --> U[上游模型]
 U --> RESPONSE[原样响应 / SSE流]
 RESPONSE --> C
 UI[三页控制台] --> API[privacy/routes.py]
 API --> S
 API --> A
 API --> TEST[privacy/preview.py · 不访问上游]
 A --> DB[(privacy.sqlite / 无正文和原值映射)]
 ERROR[缓冲 / 解析 / 识别 / 校验 / 登记失败] --> STOP[明确错误 / 不建立上游请求]

03 · 先检查后外发的时序

sequenceDiagram
 participant C as 客户端
 participant G as 网关
 participant P as 本机隐私处理
 participant DB as 风险记录库
 participant U as 上游模型
 C->>G: 含敏感数据的请求
 G->>P: 冻结策略 / 完整缓冲 / 不建立上游连接
 P->>P: 识别敏感值 / 全请求一致替换
 P->>P: 校验可改写路径 / JSON结构 / 已识别原值残留
 alt 处理失败或无法覆盖
 P-->>G: blocked + 无原文错误码
 G-->>C: 拒绝本次请求
 else 已脱敏
 P->>DB: 先写最小风险记录 / 不含正文
 DB-->>P: 持久化成功
 P-->>G: 仅返回脱敏后字节与出站许可
 G->>U: 脱敏请求 + Provider鉴权
 U-->>C: 经网关透传响应流
 else 未命中所选规则
 P-->>G: 检查通过 / 未命中不等于安全保证
 G->>U: 检查后的请求
 end
 Note over G,U: 检查和登记失败不允许回退发送原文

04 · 识别、去重与替换

flowchart TD
 TEXT[完整解码后的请求字符串 / JSON值] --> R1[格式规则：邮箱 / 手机 / 身份证候选 / 常见Key前缀]
 TEXT --> R2[字段与上下文：密码 / username / api_key / host]
 TEXT --> R3[服务器：SSH登录 / 数据库连接串 / 私钥块]
 TEXT --> R4[自定义业务字段名 / 禁止任意用户正则]
 R1 --> SPAN[命中区间 / 类别 / 规则版本]
 R2 --> SPAN
 R3 --> SPAN
 R4 --> SPAN
 SPAN --> MERGE[重叠优先完整凭据块 / 最长区间优先]
 MERGE --> MAP[全请求建立唯一原值映射 / 同值同占位符]
 MAP --> REPEAT[已识别原值的其他出现位置同步替换]
 REPEAT --> CHECK[复查已知原值残留 / 不递归替换生成的占位符]
 CHECK --> OUT[业务文本保留 / 敏感值用占位符]
 UNK[任意无标签密码或人名] --> LIMIT[不能保证检出 / 业务字段与语料回归补充]

05 · 协议覆盖与失败边界

flowchart TD
 REQ[请求体 / 上游路径与用户透传头] --> TYPE{可完整检查并安全改写}
 TYPE -- 是 --> JSON[Responses / Chat Completions / Claude Messages]
 JSON --> STRING[扫描system / messages / input / instructions及嵌套文本]
 STRING --> PROTECTED[保护model / role / type / 工具名等结构标识]
 PROTECTED --> MATCH{结构字段是否命中秘密}
 MATCH -- 是 --> BLOCK[阻止外发 / 不静默破坏协议]
 MATCH -- 否 --> REWRITE[仅修改合法字符串值 / 重算Content-Length]
 REWRITE --> PASS[模型名不限 / stream和参数类型保留]
 TYPE -- 否 --> BLOCK
 MEDIA[附件 / 音视频 / 图像 / 文件引用 / 压缩未知编码] --> BLOCK
 WS[WebSocket / 未知协议] --> BLOCK
 HEADER[非必要用户头 / 含秘密的URL查询] --> BLOCK
 AUTH[Provider授权密钥 / 必要可信协议头] --> INJECT[在检查后独立注入 / 不进入风险正文]

06 · 防护决策与转发状态

stateDiagram-v2
 [*] --> buffering
 buffering --> inspecting: 请求完整且预算内
 buffering --> blocked: 超限或读取失败
 inspecting --> replacing: 有敏感命中
 inspecting --> validated: 所选规则未命中
 inspecting --> blocked: 不支持或识别超时
 replacing --> validated: 残留与结构校验通过
 replacing --> blocked: 替换或校验失败
 validated --> recording: 有风险
 recording --> authorized: 记录持久化成功
 recording --> blocked: 风险记录不可写
 validated --> authorized: 未命中无需风险登记
 authorized --> forwarding: 建立唯一上游请求
 forwarding --> completed
 forwarding --> upstream_failed
 blocked --> [*]
 completed --> [*]
 upstream_failed --> [*]
 note right of authorized
 防护结果redacted或unchanged不等于上游成功
 风险库独立保存forward_state
 end note

08 · 秘密生命周期与不可留存字段

flowchart LR
 RAW[请求原文] --> MEM[有界内存 / 禁止日志与持久缓存]
 MEM --> MAP[临时替换映射 / 仅当前请求]
 MAP --> SAN[脱敏请求]
 SAN --> UP[上游模型]
 SAN --> DISCARD[转发结束释放引用 / 不保证运行时物理内存擦除]
 MAP --> DISCARD
 META[风险类型 / 受控路径 / 占位符 / 决策 / 策略版本] --> DB[(风险库)]
 NO[明确不存] --> N1[原始秘密 / 原文摘要 / 原值哈希]
 NO --> N2[出站全文 / 可逆映射 / 任意自由文本反馈]
 DB --> TTL[默认30天 / 到期不可读 / 定期清理]
 TTL --> CLEAN[风险与命中明细及反馈级联清理]
 EXPORT[导出] --> SAFE[只导出元数据 / 同筛选条件]

09 · 策略变更与生命周期

flowchart TD
 EDIT[编辑策略版本N] --> CAS{提交expected_revision N}
 CAS -- 不匹配 --> CONFLICT[409 / 保留草稿 / 重新载入]
 CAS -- 匹配 --> SHRINK{关闭保护类别}
 SHRINK -- 是 --> CONFIRM[展示失去覆盖的类别 / 明确确认]
 SHRINK -- 否 --> COMMIT[保存并原子激活N+1]
 CONFIRM --> COMMIT
 COMMIT --> NEW[新请求使用N+1]
 OLD[处理中请求] --> FREEZE[继续使用开始时的策略与规则快照]
 COMMIT --> RET[缩短期限收紧历史expires_at / 延长仅新记录]
 DEL[清理预览] --> TOKEN[固定ID集合 / 60秒 / 单次令牌]
 TOKEN --> RECHECK[确认时复核操作者 / 策略版本 / 有效期]
 RECHECK --> DELETE[仅删除预览集合 / 新增记录保留]

10 · 超时、并发与失败处理

flowchart TD
 R[请求进入] --> ADMIT{全局缓冲槽与字节预算}
 ADMIT -- 不足 --> BUSY[503 privacy_busy / 上游零请求]
 ADMIT -- 足够 --> BUFFER[请求上限默认64KiB / 最大1024KiB]
 BUFFER --> WORK[独立处理Worker / 总检查默认1000ms]
 WORK --> TIMEOUT{检查时限内完成}
 TIMEOUT -- 否 --> STOP[取消等待 / 废弃迟到结果 / 不外发]
 TIMEOUT -- 是 --> VERIFY[结构与已知秘密残留复查]
 VERIFY --> LOG[带风险请求先持久化最小登记]
 LOG -- 失败 --> STOP
 LOG -- 成功 --> SEND[发送唯一检查后版本]
 CANCEL[客户端取消 / 进程重启] --> DROP[释放缓冲 / 不重放原请求]
 RESTART[启动恢复] --> MARK[旧forwarding标记interrupted / 不猜测上游执行结果]

11 · 交付与验收边界

flowchart TD
 NOW[当前：交互原型 / 架构 / 接口评审] --> REVIEW[用户review]
 REVIEW --> IMPL[实施本机识别与脱敏闸门]
 IMPL --> WIRE[接入真实Provider转发 / 风险库 / Docker持久卷]
 WIRE --> TEST[真实上游抓包验收]
 TEST --> T1[敏感原值不出现 / 普通内容保持]
 TEST --> T2[超时或失败时上游请求数为零]
 TEST --> T3[原文与原值映射不进入日志数据库导出]
 TEST --> T4[规则语料评估漏检误检 / 三协议 / 跨块及转义]
 MOCK[本轮原型测试] --> UI[真实文本替换与页面流程 / 不代表生产网关已防护]
