执行边界 · 设计假设

flowchart TB
 CLIENT[客户端] --> GATE[既有转发网关] --> PROVIDER[任意已配置模型]
 PROVIDER --> GATE --> CLIENT
 GATE -.有界采集输入输出文本.-> QUEUE[异步审计队列]
 QUEUE --> ENGINE[审计引擎 / 冻结策略版本]
 ENGINE --> EVENT[风险结论 + 证据 + 覆盖范围]
 QUEUE --> FAILURE[排队失败 / 超时 / 解析失败]
 FAILURE --> UNKNOWN[未完成审计：不可标为安全]
 EVENT --> STORE[受控内容存储 / 查看权限 / 保留期]
 LIMIT[二进制或未知协议] --> UNSUPPORTED[未覆盖：不限制模型转发]
