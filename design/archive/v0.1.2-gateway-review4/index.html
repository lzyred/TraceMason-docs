04 · 入口、策略与转发状态

每账号入口与策略快照

flowchart TD
 URL[proxy / account_id / raw_path] --> ACCOUNT{账号存在且启用}
 ACCOUNT -- 否 --> REJECT[404或409 · 明确错误]
 ACCOUNT -- 是 --> SNAP[冻结账号配置与relay_revision]
 SNAP --> CAP{并发槽位可用}
 CAP -- 否 --> RATE[429 · 不排队不重试]
 CAP -- 是 --> CONN[连接上游 · connect timeout]
 CONN --> STREAM[原样流式转发 · idle timeout]
 STREAM --> END[结束 / 总时长超时 / 客户端取消]
 END --> RELEASE[取消上游并释放并发]
 CONF[修改超时与并发] --> NEXT[仅新请求使用新修订]
 NEXT --> SNAP

传输与模型状态独立

flowchart LR
 REQUEST[请求] --> T[传输 running / complete / failed / cancelled / interrupted]
 REQUEST --> S[模型 pending / completed / incomplete / failed / unknown / unsupported]
 REQUEST --> U[用量 known / partial / missing / pending / unsupported]
 REQUEST --> O[观测 full / partial]
 HTTP[HTTP429已读取完成] --> H[传输complete · 调用结果上游拒绝]
 CANCEL[完成事件后断连] --> C[传输cancelled · 模型completed]
 RESTART[服务重启] --> R[旧running变interrupted · 保留已确认事实]

05 · 采集与脱敏

请求开始时冻结采集策略

flowchart TD
 START[新请求] --> POLICY[冻结capture_revision和适用账号]
 POLICY --> META[始终采集受限元数据]
 POLICY --> MODE{启用脱敏内容}
 MODE -- 否 --> NONE[not_collected · 不可回填]
 MODE -- 是 --> PROTOCOL{支持内容协议}
 PROTOCOL -- 否 --> UNSUPPORTED[unsupported · 转发继续]
 PROTOCOL -- 是 --> EXTRACT[受限解析文本与工具参数]
 EXTRACT --> MASK[凭据排除 + 邮箱电话可选脱敏]
 MASK --> BUDGET{内容字节预算}
 BUDGET -- 超限 --> TRUNCATE[脱敏后截断 · truncated]
 BUDGET -- 范围内 --> CONTENT[available]
 CONTENT --> ENCRYPT[独立密钥引用加密落盘]
 TRUNCATE --> ENCRYPT
 ERROR[解析/脱敏异常] --> DROP[丢弃该内容 · 标记partial]
 META --> DB[(元数据)]
 ENCRYPT --> DB2[(脱敏内容)]

采集完整性与运行状态

flowchart LR
 GLOBAL[当前队列或存储降级] --> HEALTH[全局健康指标]
 GAP[某请求发生数据缺口] --> ROW[仅该请求 observation=partial]
 GLOBAL -.不回写历史.-> OLD[已确认完整的历史记录]
 HEALTH --> UNKNOWN[未追踪请求只有数量 · 不伪造记录]
 ROW --> EVIDENCE[保留已确认值 · 未知不记零]

06 · 交互、工具与关联

可靠关联优先级

flowchart TD
 RAW[已识别请求事件] --> EXPLICIT{显式会话标识}
 EXPLICIT -- 有 --> SCOPE[校验格式与长度 · account_id命名空间]
 EXPLICIT -- 无 --> PREV{可验证的previous_response_id}
 PREV -- 有 --> LOOKUP[同账号查response_id]
 LOOKUP --> MATCH{唯一匹配且无冲突}
 MATCH -- 是 --> EDGE[保存引用边与来源]
 MATCH -- 否 --> UNASSIGNED[独立请求 · 原因冲突或缺失]
 PREV -- 无 --> UNASSIGNED
 SCOPE --> GROUP[会话与turn分组]
 GROUP --> EDGE
 TOOL[tool call_id与tool result] --> BIND[同账号同关联范围匹配]
 BIND --> EDGE
 EDGE --> UI[输入输出 / 工具时间线 / 关联链路]
 CONTENT[相似内容或时间接近] -.不用于硬关联.-> UNASSIGNED

09 · 查看权限与数据生命周期

权限服务端执行

flowchart LR
 LOGIN[管理会话 · 管理员或观察者] --> AUTHZ[统一授权]
 AUTHZ --> READ[两角色可读元数据与聚合]
 AUTHZ --> WRITE[仅管理员修改配置与发起检查]
 AUTHZ --> CONTENT{管理员且当前策略允许内容查看}
 CONTENT -- 是 --> AUDIT[审计后读取或导出脱敏内容]
 CONTENT -- 否 --> DENY[403 · 不返回内容字段]
 CLIENT[API转发客户端] --> ISOLATE[转发端口无管理路由]
 REVIEW[原型身份切换] --> MOCK[仅演示权限 · 生产使用服务端会话]

保留、清理与导出

flowchart TD
 META[元数据保留策略] --> TIMER[定时清理已结束请求]
 CP[内容保留策略] --> EXP[expires_at取请求捕获上限与当前缩短期限最小值]
 EXP --> DELETE[删除内容 · 元数据仍可查]
 TIMER --> CASCADE[删除关联用量/工具/内容 · 外链显示已过期]
 PURGE[管理员确认删除全部内容] --> DELETE
 EXPORT[导出预览] --> CHECK[再次校验权限与策略修订]
 CHECK --> FILE[仅保留元数据或脱敏内容 · JSON]
 FILE --> LOG[审计导出范围与条数]
 LOG --> NOTICE[本地导出副本不随服务端删除撤回]

10 · 容量、故障与恢复

有界观测与非阻塞转发

flowchart TD
 ADMIT[4096生命周期槽位 · 每槽4KiB] --> ACCEPT{接纳成功}
 ACCEPT -- 否 --> COUNT[untracked_requests加一 · 转发继续]
 ACCEPT -- 是 --> SLOT[预留start/finish同一槽位]
 SLOT --> BYTES[8MiB字节队列 · 2048事件]
 BYTES --> PARSE[128个解析上下文 · 每个1MiB]
 PARSE --> CONTENT[内容预算 · 每请求上限且全局16MiB]
 BYTES -- 满 --> PARTIAL[该请求partial · 停止其内容解析]
 SLOT --> FINAL[终态写回预留槽位]
 FINAL --> DB{串行提交成功}
 DB -- 是 --> RELEASE[释放槽位]
 DB -- 否 --> RETRY[0.1至5秒退避 · 合并受限快照]
 RETRY --> DB
 RESTART[重启] --> REC[旧running恢复为interrupted]
 REC --> LIMIT[未落盘内容无法补回]

身份、权限与导出状态机

flowchart TD
 ANON[未登录] --> LOGIN[管理员或观察者登录]
 LOGIN --> CHECK{口令验证与失败限流}
 CHECK -- 失败 --> ANON
 CHECK -- 成功 --> SESSION[8小时会话 · HttpOnly cookie与CSRF]
 SESSION --> META[可读元数据]
 SESSION --> ROLE{管理员}
 ROLE -- 是 --> WRITE[配置与检查]
 ROLE -- 否 --> DENY[拒绝写操作与内容查看]
 ROLE -- 是 --> POLICY{当前内容访问策略允许}
 POLICY -- 是 --> PREVIEW[内容读取或导出预览]
 POLICY -- 否 --> DENY
 PREVIEW --> RECHECK[确认时复核角色/修订/数据存在/预览有效期]
 RECHECK --> EXPORT[导出并审计]
 SESSION --> LOGOUT[退出/过期 · 会话撤销]
 LOGOUT --> ANON
