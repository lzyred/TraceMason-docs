sequenceDiagram
 participant C as 客户端
 participant G as 转发网关

04 · 输入、输出与流式覆盖

flowchart TD
 RAW[请求 / 响应文本] --> PROTO{协议是否识别}
 PROTO -- 否 --> NO[unsupported · 转发不受限]
 PROTO -- 是 --> EXTRACT[Responses / Chat Completions / Messages 适配解析]
 EXTRACT --> INPUT[输入：所选请求内全部文本角色]
 EXTRACT --> OUTPUT[输出：重组文本增量直到终态或断流]
 INPUT --> BOUND[每方向默认64KiB / 最大1024KiB]
 OUTPUT --> BOUND
 BOUND --> FULL{预算内且完整收到}
 FULL -- 是 --> COMPLETE[coverage full：所选文本完整]
 FULL -- 否 --> PART[coverage partial：截断 / 数据块丢失 / 流中断]
 PART --> SCAN[只检测已保留文本片段]
 COMPLETE --> SCAN
 TOOLS[工具参数 / 二进制 / 音视频 / WebSocket] --> UNCOVERED[不做工具链或多模态分析 / 明示未覆盖]
 ERROR[上游HTTP错误或无模型内容] --> SKIP[skipped / upstream_error 或 no_text]

05 · 结论、覆盖与复核独立

stateDiagram-v2
 [*] --> pending: 任务持久化
 pending --> running: 获得租约
 running --> risk: 合法命中类别与证据
 running --> clear: 合法结果未命中已选类别
 running --> failed: 超时 / 鉴权 / 格式无效 / 进程中断
 [*] --> unsupported: 内容协议不支持
 [*] --> skipped: 停用 / 范围外 / 无文本
 risk --> [*]
 clear --> [*]
 failed --> [*]
 note right of clear
 coverage partial 必须显示“已审片段未发现风险”
 不支持 / 未审计 / 失败不能转成 clear
 end note
 note right of risk
 review 独立：unreviewed / confirmed / false_positive
 人工意见追加留痕，不覆盖检测结论
 end note

07 · 内容保护与检测服务边界

flowchart LR
 EXTRACT[提取正文 / 排除鉴权头与凭据字段] --> TEMP[待审文本临时加密 / TTL最多30分钟]
 TEMP --> GUARD[仅发往用户配置的检测服务]
 GUARD --> VALIDATE[校验类别 / 枚举 / 证据归属 / 结果长度]
 VALIDATE --> MASK[正文与证据统一脱敏]
 MASK --> STORE[加密留存 / 默认7天]
 STORE --> READ[本机管理边界 + 管理令牌]
 READ --> LOG[记录内容读取动作 / 不记正文]
 EXPIRE[内容过期或删除] --> WIPE[删除正文和证据 / 保留受限元数据]
 META[元数据默认30天] --> DELETE[级联清理事件 / 内容 / 复核]
 CONFIG[缩短保留期] --> SHORT[收紧既有期限]
 CONFIG --> EXTEND[延长只影响新事件]
 LIMIT[凭据模式无法保证识别所有秘密] --> TRUST[检测端点是内容接收方 / 配置时明确告知]

08 · 策略修改与重审

flowchart TD
 EDIT[读取配置 revision N] --> SAVE[PUT config / expected_revision N]
 SAVE --> CAS{当前版本仍为N}
 CAS -- 否 --> CONFLICT[409 / 重新载入 / 禁止覆盖]
 CAS -- 是 --> COMMIT[事务保存 N+1 / 记录变更]
 COMMIT --> LOAD[原子加载策略与检测凭据引用]
 LOAD --> NEW[仅新任务使用 N+1]
 OLD[执行中的任务] --> SNAP[继续使用冻结策略与凭据引用]
 EVENT[历史事件] --> RE{可用内容未过期}
 RE -- 否 --> GONE[410 / 不可重审]
 RE -- 是 --> CHILD[按当前策略新建子事件 / 请求ID保持]
 CHILD --> PART[只能检测留存脱敏片段 / coverage partial]
 CHILD --> KEEP[原事件与原结论不变]

09 · 容量、失败与恢复

flowchart TD
 OFFER[数据块入观测队列] --> FULL{内存事件或字节预算已满}
 FULL -- 是 --> DROP[增加 dropped / 已知事件标记 partial]
 DROP --> CONTINUE[转发继续 / 不补造未知请求]
 FULL -- 否 --> PERSIST[独立写入线程 / audit.sqlite]
 PERSIST --> DURABLE[任务与临时加密载荷同事务]
 DURABLE --> LEASE[Worker 获取租约]
 LEASE --> DETECT[检测超时上限30秒 / 结果上限256KiB]
 DETECT --> RESULT[结果与完成状态事务提交]
 DBERR[数据库不可写] --> PAUSE[停止审计接纳 / 展示降级与丢失计数]
 PAUSE --> DBBACK[数据库恢复后仅接纳新事件]
 RESTART[进程重启] --> INTERRUPTED[租约过期 running 标记 interrupted失败]
 RESTART --> PENDING[未过期 pending 可继续处理]
 EXPIRED[临时载荷过期] --> FAILED[失败 payload_expired]
 FAILED --> MANUAL[有留存内容时可人工新建重审]
