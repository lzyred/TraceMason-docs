02 · 四个功能板块 / 两个页面入口

flowchart TD
 APP[Mini客户端] --> HOME[主界面：连接切换]
 APP --> SET[设置]
 HOME --> TABS[可搜索工具选择器 / 默认已检测或已启用]
 TABS --> LIST[连接列表 / 当前生效项 / 一键切换]
 LIST --> EDIT[连接配置 / URL / 凭据 / 可选模型]
 TABS --> BACK[备份恢复 / 差异预览 / 外部修改冲突]
 SET --> PATH[工具路径 / 托盘 / 启动偏好]
 SET --> DIAG[脱敏诊断 / 软件版本]
 TRAY[托盘快捷入口] --> LIST
 PROVIDER[DeepSeek等属于连接供应方] -.不作为工具页签.-> EDIT

03 · 配置切换与恢复闭环

flowchart LR
 READ[读取真实工具配置] --> CHECK[检查格式与当前文件版本]
 CHECK --> PREVIEW[预览必要字段改动]
 PREVIEW --> BACKUP[保存受保护备份]
 BACKUP --> WRITE[按工具适配器修改连接字段]
 WRITE --> VERIFY[写入后核对]
 VERIFY --> OK[更新生效标记 / 提示工具加载方式]
 WRITE -->|失败| RESTORE[恢复先前配置或显示待恢复]
 CHECK -->|外部修改冲突| CONFLICT[停止覆盖 / 重新预览与确认]
 VERIFY -->|不一致| RESTORE
 MODEL[模型名称自由填写] --> WRITE

04 · 技术职责

flowchart BT
 OS[系统凭据存储 / 本机文件系统 / 托盘] --> RUST[Rust本机能力层]
 RUST --> ADAPTER[工具适配器注册表 / JSON·TOML·YAML·env]
 RUST --> STORE[本机 JSON 元数据 / 恢复记录]
 RUST --> HTTP[HTTP诊断 / URL与凭据处理]
 ADAPTER --> TAURI[Swift 本机操作 / Rust 编辑器]
 STORE --> TAURI
 HTTP --> TAURI
 TAURI --> UI[SwiftUI / AppKit]
 UI --> MINI[精简窗口 / 连接切换与设置]

05 · 本版边界与远程前提

flowchart TD
 CLIENT[v0.1.3只做客户端] --> REMOTE[支持配置现有可访问的远程端点]
 REMOTE --> LIMIT[现有v0.1.2仅本机访问 / 客户端不能替代服务端远程能力]
 CLIENT --> KEEP[服务端维持v0.1.2定版]
 CLIENT --> OMIT[本版不实现聊天 / 任务工作台 / 配对新接口]
 OMIT --> OTHER[MCP / Skills / 本地代理 / 协议转换 / 计费另行规划]
 CLIENT --> NEXT[macOS Universal DMG]
 NEXT --> REVIEW[真实工具兼容性逐项验收]
