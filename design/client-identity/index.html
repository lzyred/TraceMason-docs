触发确定行为
启动、唤醒、临近到期建议提前 24 小时领取。Server 自签发起计 168 小时，旧代到期独立生效。离线指数退避，恢复联网立即核对服务端时间。
不同 CLI 进度不同同一客户端共享一代 Key，按工具独立切换。新旧两代短暂并存，旧代确认退役或到期后拒绝新请求；已受理流允许结束。撤回线路立即阻止该线路新请求。
外部 CLI / 并发启动Mini 托管启动用互斥门闩与活动计数。外部 CLI 无可靠活动证据时显示未知，由用户退出后明确确认，再复查进程和配置。历史 Session、网关无流量均不能证明空闲；外部并发启动仍需实际 CLI 验证。
配置外改 / 应用中断应用前比较预览指纹，冲突时重新预览。多文件保存原值、权限和阶段，逐文件原子替换。重启按指纹继续或恢复，仅恢复仍匹配本次写入的文件。凭据和含密备份受钥匙串保护。
下一代也过期 / 工具卸载以设备会话重新领取有效代，重新检查每个工具。缺失工具提示用户解除纳管，在线撤销身份始终优先于本地恢复。

POST …/activation 或 …/revoke		通过本机管理会话更新名称与授权，版本冲突返回 409。撤销身份级联失效激活码、会话及各代 Key。
Mini 首次绑定POST /device/activate激活码有效 1 小时。消费码、递增绑定修订号、创建设备会话及首代 Key 在同一事务完成，返回 client_id、revision、device_session、gateway_key、generation、expires_at、server_time 和授权目录。响应丢失由管理员重新配对并撤销旧绑定；重复消费拒绝。
已绑定设备GET /device/me
POST /device/rotations
POST /device/rotations/ack		设备会话仅作用于自身。续领绑定 operation_id、客户端和前代，同操作重试回放加密暂存的同一响应；不同操作并发返回 409，Mini 复用钥匙串中的操作编号。确认后销毁回放密文，重复确认返回最终状态。
CLI/proxy/{account}/{tail}
/catalog/{account}		按协议取临时凭据，歧义拒绝。未认证、到期或撤销返回 401，未授权线路统一 403；校验后再解析账号，目录与转发同策略。凭据在日志中仅以 key_id 表示。
Mini 验证页POST /device/verifications
GET /device/verifications/{id}		采用日常配置与环境正常启动 CLI，由 Mini 将短时随机标识放入合成验证提示。网关在入站提取并移除标识，记录匹配到的身份、账号、代号与隐私结果。标识一次消费，仅匹配本次预期元组。在服务端关联真实请求。未能唯一关联显示待核实；模型目录成功与生成正文成功分别展示。

双端实施契约 · R3

触发与责任方实施规则
管理端划分客户端本机管理员查询此实例的客户端列表，按 account_id 授权，允许清空。Mini 保存每个工具选择的账号及模型。账号被停用、删除或撤权即从有效授权集合移除。旧本机配置保留并标记失效，使用者可显式改选其他账号。
管理端重新绑定签发激活码时增加 revision，同事务撤销旧会话和旧代，保留 client_id、名称、授权与历史。设备会话有效 30 天，到期后由管理员重新配对。永久撤销进入终态。有效的模型 Key 仍按自己的到期时间判定，换绑立即作废。
服务部署与 Mini 网络层新增可配置设备监听端口及公开 base URL，HTTP 与 HTTPS 同契约，TLS 可在代理终止。设备入口按令牌鉴权，Mini 禁止重定向携带凭据。设备入口只注册 /device、/proxy、/catalog。Mini 的设备探针、模型测试和审计使用此入口，停止向远端索取 /api/session。管理控制台继续使用回环监听。远端 HTTP 中的临时令牌按明文传输。
协议转换Codex 使用 /proxy/{account}/v1 和 Bearer，Claude 使用 /proxy/{account} 和 x-api-key 或 Bearer，Gemini 使用 /proxy/{account} 和 x-goog-api-key。网关先校验本地 Key，再按所选账号注入厂商凭据。目录和转发共用授权检查，成功响应不包含上游凭据。
Mini 触发对账启动、恢复联网、纳管或授权变化、确认回执、活动变化与定时唤醒触发同一协调器。目标集合是已纳管且仍授权的工具，缺失或未知保留待处理，用户可解除纳管。集合为空可直接确认。离线期间 Server 仍按 UTC 判定到期。过期待确认代标记失效，重新续领使用单调递增代号。
续领、验证及确认/device/me 返回授权版本、当前代与待确认代元数据。签发按客户端、前代和 operation_id 去重。Mini 按纳管工具回读配置并查询审计结果，全部验证后重新核对本机纳管集合。ack 携带目标代与授权版本；服务端事务检查设备会话、授权版本和待确认代，版本过旧返回 409 并刷新。已完成的同一 ack 返回原结果。丢回包先读 /device/me，匹配已提交代即可结束。
请求处置与轮换完成确认某工具使用新代所需证据为正常配置启动、网关鉴权成功、唯一匹配验证记录。隐私拦截和厂商错误分别展示，均可证明本次网关认证。请求未关联只显示待核实。对外部启动环境无法复现时提示用户在其正常终端发起验证。
