远程入口仅发布设备与网关路由。管理、备份、设备续签和模型请求各用独立权限。首期将现有单管理员映射到持久 owner_id，部署迁移时先建立授权，再开启远程入口。回环兼容模式与远程入口独立监听，默认拒绝未知路由。

触发确定行为
启动、唤醒、临近到期建议提前 24 小时领取。Server 自签发起计 168 小时，旧代到期独立生效。离线指数退避，恢复联网立即核对服务端时间。
不同 CLI 进度不同同一客户端共享一代 Key，按工具独立切换。新旧两代短暂并存，旧代确认退役或到期后拒绝新请求；已受理流允许结束。撤回线路立即阻止该线路新请求。
外部 CLI / 并发启动Mini 托管启动用互斥门闩与活动计数。外部 CLI 无可靠活动证据时显示未知，由用户退出后明确确认，再复查进程和配置。历史 Session、网关无流量均不能证明空闲；外部并发启动仍需实际 CLI 验证。
配置外改 / 应用中断应用前比较预览指纹，冲突时重新预览。多文件保存原值、权限和阶段，逐文件原子替换。重启按指纹继续或恢复，仅恢复仍匹配本次写入的文件。凭据和含密备份受钥匙串保护。
下一代也过期 / 工具卸载以设备会话重新领取有效代，重新检查每个工具。缺失工具提示用户解除纳管，在线撤销身份始终优先于本地恢复。

目标接口与持久化

调用方接口草案服务端约束
本机管理员POST /admin/clients
PATCH /admin/clients/{id}
POST …/activation 或 …/revoke		从管理会话取 owner，名称与授权分开更新，版本冲突返回 409。撤销身份级联失效激活码、会话及各代 Key。
Mini 首次绑定POST /device/activate短时单用码摘要，条件更新与创建设备会话同事务。响应丢失由管理员重新配对并撤销旧绑定；重复消费拒绝。
已绑定设备GET /device/me
POST /device/rotations
POST /device/rotations/{id}/ack		设备会话仅作用于自身。续领绑定 operation_id、客户端和前代，同操作重试回放加密暂存的同一响应；不同操作并发返回 409 并查询进行中编号。确认后销毁回放密文，重复确认返回最终状态。
CLI/proxy/{account}/{tail}
/catalog/{account}		按协议取临时凭据，歧义拒绝。未认证、到期或撤销返回 401，未授权线路统一 403；校验后再解析账号，目录与转发同策略。凭据在日志中仅以 key_id 表示。
Mini 验证页POST /device/verifications
GET /device/verifications/{id}		验证使用短时路径别名，映射回授权线路；仅为新启动的验证进程注入该地址，CLI 无法注入时显示待核实。验证前申请短时标识，绑定客户端、线路、代号和工具。在服务端关联真实请求。未能唯一关联显示待核实；模型目录成功与生成正文成功分别展示。

源码与验收对照

当前可核对的事实本轮验收条件
现有宿主端口仅绑定回环，网关挂有目录及代理路由。Compose · 路由第二台设备分别使用 HTTP 和 HTTPS 完成激活、续领与网关请求；管理入口不可达；跨客户端请求其他线路和目录均被拒绝，厂商调用计数为零。
配对设备令牌属于版本化备份。备份服务 · Mini 同步备份令牌调用模型、模型 Key 调用续领、其他设备读取验证记录均被拒绝。
Mini 已有安装检查、配置读取与 CLI 审计入口。安装检测 · 配置读取 · 审计关联逐一验 Codex、Claude、Gemini 的缺失、外部会话、真实生成、隐私拦截。每次展示工具、线路、模型、结果；关联失败可见。
R1 原型使用单个全局活动开关，确认写入即显示已应用。原始交互Codex 忙时 Claude 可独立切换；未知状态保持待处理。回读成功而 CLI 验证失败时，仍保留旧代至退役或到期。
轮换协议属于本轮设计双续领只产生一代；丢响应可恢复；逐文件中断、确认丢包和重启均可续办；到期边界拒绝新请求；撤销后旧新两代均失效。
