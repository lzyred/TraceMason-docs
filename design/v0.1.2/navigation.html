02 · 工作台按原型恢复的板块

flowchart TD
 H[工作台 / 四步任务流程 / 当前轮次] --> LEFT[左侧：任务输入与材料]
 H --> RIGHT[右侧：交付决定与证据]
 LEFT --> TASK[这次要让 AI 做什么 / 任务描述 / 交付对象]
 TASK --> MODEL[真实调用补充：模型 / 折叠的连接协议]
 TASK --> MAT[本轮材料 / 添加文本与工具返回 / 选择文件]
 MAT --> ACTION[查看修改 / 排除 / 重新纳入 / 生成清单]
 MAT --> REPLY[发送后：模型回复与下一轮补充]
 RIGHT --> MAN[模型将拿到什么 / 本轮外发清单]
 MAN --> COUNTS[保留材料 / 已处理片段 / 不交付材料]
 COUNTS --> REVIEW[逐项决定 / 只确认脱敏候选]
 REVIEW --> SEND[交付内容预览 / 实际发送]
 SEND --> FINDINGS[本轮处理明细 / 材料·信息类型·处理结果]
 FINDINGS --> LIMIT[覆盖边界 / 进入防护边界]
 DEMO[原型中的样例装载与预演] -.不进入正式页面.-> REAL[真实账号 / 真实材料 / 真实响应]
