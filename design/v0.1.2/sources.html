flowchart TD
 OWASP[OWASP Sensitive Information Disclosure] --> PRINCIPLE[最小权限 / 限制数据来源 / 输入处理]
 INJECT[OWASP Prompt Injection Prevention] --> LAYERS[内容与授权分离 / 分层验证 / 输出不自动执行]
 LAYERS --> LOCAL[本版本本机规则与强制校验 / 不是意图分类器]
 PRESIDIO[Presidio Analyzer] --> CANDIDATE[规则 + NER + 上下文识别的候选参考]
 CANDIDATE --> VALIDATE[不直接认定适用 / 中文与业务语料验证]
 SUB[sub2api配置与事件工作台] --> UI[仅借鉴列表和配置操作]
 NEW[new-api Provider适配] --> BASE[既有接入层参考]
 SOURCE[这些参考] --> NOT[不能替代本产品的外发授权与任务边界]
