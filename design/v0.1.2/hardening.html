02 · 执行标准与风险分级

flowchart TD
 A[local-context-3 / 本机有限规则] --> S[认证秘密 / 高风险]
 S --> S1[密码与私钥 / API Key / Cookie / JWT / 登录凭据]
 S1 --> S2[默认移除 / 可收紧为拦截]
 A --> I[已识别身份与环境 / 中风险]
 I --> I1[姓名 / 邮箱 / 手机 / 用户路径 / 主机线索]
 I1 --> I2[默认别名替换 / 可收紧为拦截]
 A --> U[格式或覆盖不足 / 风险未知]
 U --> U1[已知敏感编码 / 远程引用或工具 / 敏感复合字段]
 U1 --> U2[拒绝 / 整理或排除后重新提交]
 A --> N[未命中 / 无已知发现]
 N --> N1[不等于不存在隐私 / 无通用NER保证]
 S2 --> P[账号策略只允许脱敏或拦截]
 I2 --> P
 P --> CAS[版本更新与历史 / 禁止原始秘密放行]

03 · 拦截后的处理闭环

sequenceDiagram
 participant C as 原客户端
 participant G as 网关
 participant D as 最小风险库
 participant U as 管理工作台
 participant P as 上游模型
 C->>G: 模型JSON含认证秘密
 G->>G: 完成检查与脱敏 / 账号策略要求拦截
 G->>D: 原请求记录A与规则依据
 G-->>C: 409 + request_id + review_available
 Note over G,U: 仅脱敏候选保留10分钟 / 最多16份
 U->>G: 从记录A单次领取候选
 G-->>U: 锁定账号模型协议 / 候选待确认
 U->>G: 裁剪确认并重建清单
 G->>D: 清单检查记录B / 前序A
 U->>G: 清单授权发送
 G->>G: 再核对策略版本与单次授权
 G->>D: 外发记录C / 前序B
 G->>P: 原协议参数与脱敏正文
 P-->>U: 真实响应经网关返回
 Note over C,U: 原客户端连接不会被恢复 / 用户决定后续流程

04 · 结果展示与证据

flowchart TD
 Q[请求编号 / 响应头与错误体] --> R[外发记录详情]
 R --> WHY[枚举原因 / 命中规则 / 信息类型 / 处理动作]
 R --> VER[账号策略版本 / 规则集版本 / 前序记录]
 R --> STATE[实际发送状态]
 STATE --> NOT[未发送 / 清单检查或拦截]
 STATE --> READY[已授权 / 尚未证明已交付]
 STATE --> GO[发送中]
 GO --> OK[2xx且流完成 / 已完成]
 GO --> BAD[非2xx或传输错误 / 失败]
 BAD --> REDIRECT[移除上游跳转头 / 阻止客户端原文重发]
 GO --> STOP[用户断开 / 取消]
 GO --> UNKNOWN[进程中断或状态写失败 / 不确定]
 OK --> LIMIT[不代表语义成功或厂商未留存]
 UNKNOWN --> NORETRY[不自动重试 / 避免重复外发]

05 · 最小存储与生命周期

flowchart LR
 INPUT[原文与模型响应] --> MEM[有界内存处理]
 MEM --> NO[不写风险库 / 不写浏览器持久存储]
 POLICY[账号策略枚举与版本] --> DB[SQLite]
 CHANGE[策略版本历史 / 30天] --> DB
 EVENT[请求编号 / 规则原因 / 风险分类 / 状态 / 前序编号] --> DB
 EVENT --> TTL[风险记录30天 / 限定预览后删除]
 CLEAN[已完成检查的脱敏候选] --> CASE[内存10分钟 / 单次领取 / 最多16份]
 CASE --> TASK[任务空闲30分钟 / 最长2小时]
 TASK --> END[结束或重启清除]
 ALIAS[同任务身份别名] --> TASK
 SECRET[秘密原值] --> DROP[仅本轮识别 / 不作跨轮映射或原值哈希]
