05 · 清单状态与竞态

stateDiagram-v2
 [*] --> 收集材料
 收集材料 --> 检查
 检查 --> 待处理: 用途或格式不确定
 待处理 --> 收集材料: 候选确认 / 排除 / 替换
 检查 --> 可发送: 全部有决定
 可发送 --> 失效: 内容或目的地或策略变更 / 120秒到期
 失效 --> 检查
 可发送 --> 已预占: 同步消耗清单
 已预占 --> 记录提交
 记录提交 --> 发送中: 当前账号与策略版本一致
 记录提交 --> 拒绝: 写入失败或任务变化
 发送中 --> 完成
 发送中 --> 失败或取消
 完成 --> 已有结果: 同幂等key重试
 失败或取消 --> 已有结果: 不自动重放
