04 · 原型与服务动作对应

flowchart LR
 P[添加账号弹窗 · Provider 选择] --> CHOOSE[选择供应方]

 SAVE --> LIST[账号管理页]
 LIST --> EDIT[编辑配置]
 LIST --> TOGGLE[启用 / 停用]
 LIST --> DELETE[确认删除]
 LIST --> DETAIL[详情 / 凭据准备]
 LIST --> TEST[可选自定义检查]
 O[Ops 页] --> REFRESH[刷新状态]
 O --> TEST
 TEST --> RESULT[记录本次结果 · 不自动停用账号]

 PROFILE -.-> CLIENT

06 · Ops 状态不混用

flowchart TB
 ACCOUNT[账号] --> ENABLE[配置状态 · enabled / disabled]
 ACCOUNT --> CRED[凭据状态 · loaded / missing]
 ACCOUNT --> UP[上游状态 · unknown / 本次通过 / 本次失败]
 UP --> TIME[展示检查时间 · 不承诺持续健康]
 MGMT[本机管理服务 · connected / unreachable] --> OPS[账号表格与检查详情]
 ENABLE & CRED & TIME --> OPS
 CHECK[自定义检查失败] --> ERROR[原因 / 错误码 / 重试]
 CHECK -. 不自动停用 .-> ENABLE
 NEVER[从未检查] --> UNKNOWN[显示未知 · 不伪造健康]

07 · Provider 通用实现边界

flowchart LR
 IN[显式账号入口 /proxy/account_id/path] --> ACCOUNT[查询账号启用状态与凭据]
 ACCOUNT --> SNAP[在途请求使用不可变快照]
 SNAP --> PATH[配置根地址 + 原路径/查询]
 PATH --> HEADER[保留端到端头 · 注入认证 · 重建传输头]
 HEADER --> STREAM[正文流与响应流直接转发]
 STREAM --> OUT[保留上游状态码 / 错误 / 未知字段]
 WS[WebSocket] --> TUNNEL[原始握手与帧 · 流控 / 压缩透传]
 MODEL[模型名称 / 版本 / 类型] --> PASS[不设白名单 / 不补写或覆盖 model]
 PASS --> STREAM
 OBS[有界元数据事件队列 · 满时丢弃] -. 失败不阻断转发 .-> STREAM
